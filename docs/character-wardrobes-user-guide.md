# Wardrobes and image models

## Characters
Open Characters, select a saved character, and expand **Wardrobe & outfit library**.
- **New personal outfit** creates a complete costume only for this character.
- **New shared outfit** creates a reusable costume within the current workspace.
- **Add to wardrobe** links a shared costume without copying it. **Personal variant** starts an independent copy.
- **Make default** selects the costume used by new default previews and photo sessions.
- **Archive** hides an outfit from new selections but retains old snapshots and previews. If it was a default, explicitly choose a replacement or clear the default.

Use **Generation model** to choose Z-Image or Krea2 Turbo. The preference is remembered in this browser. Choose an **Outfit mode**, then Generate on Portrait, Upper-body or Full-body. **Neutral anatomy** is an explicit simple-swimwear mode; it does not alter the character's default outfit. **Saved look previews** keeps variants with their model and costume names.

## Studio
A session brief selects Character default, Choose outfit or Custom outfit. Custom text replaces the default outfit. New runs freeze the chosen identity and costume. Later library edits do not change existing runs.

Choose a model in **New run** or **Run settings**. When switching models, clear incompatible LoRAs before saving. Krea2 Turbo uses the pose prompt only and does not use OpenPose/ControlNet. Existing launched jobs are not changed.

The Pose Library also has a generation-model selector for individual and bulk previews. Bulk generation retains its confirmation step.

## Prompts
Selecting a library character fills identity and its default outfit in that character slot. For a linked character, choose an outfit mode and use **Apply selected outfit**. This refreshes only that slot's identity and costume, preserving its pose and staging. Other slots and old saved prompt documents are not rewritten when wardrobe records change.
